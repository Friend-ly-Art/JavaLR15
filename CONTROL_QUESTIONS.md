# Ответы на контрольные вопросы

1. **Что такое система контроля версий и зачем она нужна?**  
   Система контроля версий сохраняет историю изменений файлов, позволяет сравнивать версии, возвращаться к рабочему состоянию и совместно разрабатывать проект.

2. **Чем Git отличается от SVN и Perforce?**  
   Git является распределённой системой: каждый разработчик хранит полную копию репозитория и его истории. SVN и Perforce обычно используют централизованный сервер, от которого сильнее зависят повседневные операции.

3. **В каких трёх состояниях может находиться файл в Git?**  
   `modified` — изменён в рабочей папке, `staged` — добавлен в индекс для следующего коммита, `committed` — сохранён в локальном репозитории.

4. **Какие основные команды Git используются?**  
   `git init`, `clone`, `status`, `add`, `commit`, `log`, `diff`, `branch`, `switch` или `checkout`, `merge`, `fetch`, `pull`, `push`, `revert` и `reset`.

5. **Что такое ветка и зачем она нужна?**  
   Ветка — независимая линия разработки. Она позволяет изолированно создавать функцию или исправление, не нарушая стабильную основную ветку.

6. **Что такое конфликт слияния и как его разрешить?**  
   Конфликт возникает, когда Git не может автоматически объединить несовместимые изменения одной области файла. Разработчик выбирает правильный вариант, удаляет маркеры конфликта, проверяет результат и создаёт коммит.

7. **Чем GitHub отличается от Git?**  
   Git — система контроля версий, работающая локально и с удалёнными репозиториями. GitHub — веб-платформа для размещения Git-репозиториев, совместной работы, Pull Request, ревью кода и автоматизации.

8. **Что такое Pull Request и зачем он нужен?**  
   Pull Request — предложение объединить изменения одной ветки с другой. Он позволяет проверить различия, обсудить код, запустить автоматические проверки и сохранить историю ревью.

9. **Что такое `.gitignore` и зачем он нужен?**  
   `.gitignore` задаёт файлы и каталоги, которые Git не должен отслеживать, например результаты компиляции, временные файлы, настройки IDE и секреты.
